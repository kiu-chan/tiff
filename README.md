# tiff

Dart library for reading and writing TIFF and BigTIFF image files — tags, IFDs, strips/tiles, and common compression schemes.

## Status

Early scaffold. API is not implemented yet.

## Features

- [ ] Classic TIFF (32-bit offsets)
- [ ] BigTIFF (64-bit offsets)
- [ ] IFD / tag parsing
- [ ] Strip and tile decoding
- [ ] Common compression schemes (none, LZW, PackBits, Deflate)

## Getting started

```yaml
dependencies:
  tiff: ^0.1.0
```

## Usage

```dart
import 'package:tiff/tiff.dart';
```
